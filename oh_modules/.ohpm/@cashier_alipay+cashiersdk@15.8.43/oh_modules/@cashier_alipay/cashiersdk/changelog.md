## 15.8.27 （重要：需要用户安装的支付宝版本 >= 10.6.50才可以唤起支付）

```
// 支持scheme唤端，不配置则打开H5支付
  "module": {
    ...
    "querySchemes": [
      "alipays"
    ],
```

## 15.8.29
- 重要：将 deepLink 形式的跳转更新为 appLink 形式的跳转，以免出现scheme劫持
- 重要：需要将 querySchemes 中的 alipays 改为 https
```typescript
// 支持scheme唤端，不配置则打开H5支付
  "module": {
    ...
    "querySchemes": [
      "https"
    ],
```
- 如果你需要其他场景通过 alipays scheme 启动支付宝的话，请保留 querySchemes 中的 alipays
